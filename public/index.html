evidencebundle

Signed evidence bundles for AI agent outputs. x402 native. USDC pay-per-call.

What it does

You give it a payload (text, JSON, or any content). It returns a cryptographically signed bundle with:

  • Timestamp (when the bundle was created)
  • Content hash (SHA-256 of your payload)
  • Payment receipt (on-chain USDC tx hash)
  • Provenance chain (who signed, when, on which network)

Verifiable on Basescan. No trust required.

How it works

The server returns 402 Payment Required if no X-PAYMENT header is sent. To pay:

  1. Send USDC (on Base) to the recipient address
  2. Get the transaction hash from your wallet
  3. Encode the payment receipt as base64 JSON
  4. Retry with X-PAYMENT: <receipt> header

Receipt format:

{
  "txHash": "0x...",
  "amount": "0.10",
  "currency": "USDC",
  "payer": "0x...",
  "network": "base-mainnet"
}
