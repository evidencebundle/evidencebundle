Comment ça marche

Tous les endpoints suivent le standard x402 (HTTP 402 Payment Required) :

  1. Appelle un endpoint sans X-PAYMENT → reçois 402 avec prix + adresse wallet
  2. Envoie USDC (sur Base) à 0x62cac459ed425f67ac0e56573084fa061bf89abc
  3. Récupère le hash de transaction depuis ton wallet
  4. Encode le reçu en JSON base64
  5. Re-tente avec le header X-PAYMENT: <receipt>
  6. Reçois ton bundle signé ou scan

Test rapide

Le plus simple — envoie 0.10 USDC à 0x62cac459ed425f67ac0e56573084fa061bf89abc sur Base, puis :

curl -X POST https://petite-friends-nail.loca.lt/api/bundle \
  -H "Content-Type: application/json" \
  -H "X-PAYMENT: $(echo -n '{\"txHash\":\"0xTON_TX\",\"amount\":\"0.10\",\"currency\":\"USDC\",\"payer\":\"0xTON_WALLET\",\"network\":\"base-mainnet\"}' | base64)" \
  -d '{"payload":"Mon premier test x402","type":"text"}'
